# VOS HybRAG Changelog

记录 VOS HybRAG 应用的可验证变化。

## [Unreleased]

- 统一 V-Scheduler 重排接口默认超时改为 180 秒，覆盖排队和首次冷加载；显式超时及调用方取消优先，外部接口默认仍为 60 秒。
- Use a 180-second default for trusted V-Scheduler reranking, covering admission and cold loading while preserving explicit deadlines and cancellation.

## [0.1.74] - 2026-10-20

### 修复

- 新建模型、自动发现和调度绑定统一使用正式 `v-scheduler` 地址；旧的统一网关兼容地址与已有模型配置继续可用。
- 调度身份通过能力协商迁移，私钥仅发送到固定的统一容器地址和推理接口；独立 Model Hub/Router 模式继续使用原有独立配置和凭据。
- 安装参数、启动脚本、模型选择界面与接入说明同步更新。此版本沿用 0.1.73 的发布基线，不包含另行合并到主分支的上游功能更新。

## [0.1.73] - 2026-10-17

### 新增

- **选择 V-Scheduler 已注册模型** — 模型编辑器可从 V-Scheduler（统一模型网关与调度服务）读取当前应用身份可见的模型，打开时刷新，也可手动刷新；选择后原样保留模型 ID 并填写网关地址，无需手工复制密钥。新增 `GET /api/v1/models/scheduler`，发现失败时提示检查应用绑定；列表不按名称判断模型能力，使用前需确认模型支持所选用途。操作说明见 [VOS 应用说明](README.md#从-v-scheduler-添加模型--add-models-from-v-scheduler)。

### 安全与权限

- **自建网关模型复用应用身份** — 发往固定统一网关的自建模型请求也使用服务端保存的应用绑定凭据，不再仅限四个内置模型；每次请求重新读取凭据以支持轮换，模型发现接口只返回模型标识和网关地址，不返回凭据。允许的请求仍限于模型列表、聊天、Embedding（内容向量化）和 ReRank（检索结果重排），禁止跟随重定向；ASR（语音识别）继续使用独立配置，个人私有上游不会因应用绑定自动共享。

## [0.1.72] - 2026-10-16

### 修复

- **root 运行时的离线表格分析扩展** — 后端镜像同时向 appuser 和 root 的默认缓存目录复制 DuckDB（表格分析数据库）的预装 `spatial`、`excel` 扩展，避免 VOS 以 root 启动时因缓存缺失而重新联网下载。需更新包含此修复的后端镜像后生效。

### 文档与验证

- **安装说明对齐可选模型服务** — 包内中英文说明明确 PGV（提供 PostgreSQL 与检索扩展的依赖应用）为唯一必需安装依赖，V-Scheduler 和 Model Hub（本地模型管理服务）均可选；补充纯云模型使用方式和 DuckDB 离线扩展说明。

## [0.1.71] - 2026-10-16

### 修复

- PGV 为唯一必需依赖，本地模型服务可选；自动模式独立添加 V-Scheduler 与旧 Model Hub 已发布的模型，纯云模型无需安装本地服务。
- 自动添加的本地模型使用独立标识，不覆盖用户云模型或默认选择；缺少本地服务不阻止启动和云模型恢复任务。
- V-Scheduler 私钥仅发送到独立统一网关；旧 Router 使用实际独立服务地址和独立凭据，避免同名 DNS 混用。旧私有绑定只能被更高修订的新网关绑定替换，不能继续用于旧网关推理。
- **旧知识库模型引用保留** — 自动模式下仅存在旧 Model Hub 时沿用 `hybrag-ollama-*` 标识，保留已有知识库的模型引用；两套服务同时可用时，旧服务使用独立的 `hybrag-modelhub-*` 标识。
- **显式旧后端的地址选择** — `HYBRAG_MODEL_BACKEND=model-hub` 不再把统一网关默认地址当作旧 Router（模型请求路由服务）地址；优先采用 `HYBRAG_LEGACY_V_ROUTER_URL`，否则按架构选择独立旧服务。旧版显式设置的非统一网关地址继续兼容，模型探测与后台重解析等待采用一致地址。

### 打包与部署

- **构建提交来源校验** — `build_image.sh` 仅在源码目录自身存在 `.git` 时读取 Git 提交号，避免复制到其他仓库下的构建目录误用父仓库提交号。

## [0.1.70] - 2026-10-16

### 打包与部署

- **移除旧模型服务的安装版本阻碍** — 应用依赖声明移除可选的 `com.ictrek.model-hub` 和 `com.ictrek.v-router`，保留运行时旧后端接入；避免旧可选依赖的版本要求阻碍 HybRAG 升级。本版本仍声明可选 V-Scheduler，PGV 为必需依赖；仅保留 PGV 依赖声明的调整见 `0.1.71`。

## [0.1.69] - 2026-10-16

### 打包与部署

- **发布流程可手动恢复** — VOS 发布工作流新增 `workflow_dispatch` 手动触发入口，仅在选定 `vos-hybrag-v*` tag（标记版本提交的标签）时执行发布任务；选择普通分支不会发布，可用于重新运行已有 tag 的打包发布流程。

## [0.1.68] - 2026-10-16

以下条目记录截至本版本 tag 的源码、配置及文档变化；后续模型后端兼容修复见 `0.1.70` 和 `0.1.71`。

### 新增

- **人工提问与交互恢复** — 智能体新增 `ask_user`，可通过文字、选项或简短表单收集用户回答；非交互渠道改为提示智能体在正文中提问。提问、MCP（模型连接外部工具的协议）工具审批和 OAuth（第三方授权）交互保存到数据库；有运行快照时，默认等待 120 秒后挂起为 `awaiting_input`，回答后继续同一条助手消息，挂起交互默认 7 天过期。可用 `agent.prompt_suspend_enabled`、`agent.prompt_hot_wait_seconds` 和 `agent.prompt_expire_seconds` 调整。新增消息或回溯会取代旧的挂起交互；已批准工具执行途中中断时标记结果未知，不自动重放。
- **`@` 菜单跨分组搜索** — 聊天资源选择器可在根层搜索多个资源分组，也可进入分组继续筛选；全局结果每组先展示最多 5 项，并提供查看全部入口，文件分组支持继续加载。

### 优化

- **会话未读与回溯确认** — 切换页面或刷新后继续跟踪已登记的回答任务，其他会话完成回答时显示未读标记，打开该会话后清除；回溯确认弹层显示期间保持操作按钮可见。
- **检索融合参数入口** — 检索设置按召回、RRF（按各路候选排名融合结果）和重排分组；管理员可编辑 `rrf_k`、`rrf_vector_weight`、`rrf_keyword_weight`，未设置时分别采用 `60`、`0.7`、`0.3`。输入 `0` 使用服务端默认值，不表示禁用某一路检索。
- **完成事件标明实际模型** — 智能体的 `complete` 事件新增可选 `model_id`，标明产生本轮用量的实际聊天模型，便于 API（应用编程接口）客户端关联用量；不改写消息中保存的请求模型选择。

### 修复

- **技能安装区分备注与阻碍** — `.weknora/install-report.json` 新增可选 `notes`，非阻断观察作为备注展示，不再因此判定安装失败；缺少必需命令、无效报告或存在 `blockers` 时仍拒绝安装。
- **共享知识库的建议问题** — 自有智能体选择全部知识库时，也从当前空间已获授权的共享知识库生成建议问题，并按工具能力筛选；借用的共享智能体不混入调用者空间的共享资源。
- **手工 Markdown 文档引用定位** — 手工录入的 Markdown（带格式标记的正文）文档可打开原文预览并定位引用，不再直接退回引用列表；常见问答条目仍沿用原展示方式。
- **附件图片地址与图表读取** — `read_file` 明确使用完整的 `attachment://<handle>/images/N` 地址，误用裸图片路径时提供修正提示；图表精读提示要求保留类别、系列与单位的对应关系，不清楚时重新读取或说明不确定性。本项不代表图表计算准确率已验证。
- **审批后的 MCP 授权提示** — 工具审批完成后仍保留交互上下文，需要 OAuth 授权时继续显示授权提示，不再因审批后更换调用上下文而丢失该入口。
- **数据库索引故障恢复指引** — PostgreSQL 索引访问错误改为提示管理员核对服务器实际扩展版本、备份并暂停写入与检索，再由索引所有者执行 `REINDEX INDEX public.embeddings_search_idx`；不再指向已不存在的旧升级脚本，应用不会自动重建索引。

### 打包与部署

- **人工交互数据库迁移** — PostgreSQL 新增 `000141_agent_prompts`，SQLite 新增 `000047_agent_prompts`，保存交互请求、挂起快照及 `messages.run_state`。升级需执行对应迁移；本项目已调整上游迁移编号，避免与既有迁移冲突。
- **依赖版本由正式发布解析** — 打包时根据依赖正式发布记录，将暂存 `manifest.yml` 的 `latest` 转为 `>=X.Y.Z`，不再固定沿用旧最低版本；未找到正式版本或所需安装包时打包失败。发布工作流增加依赖目录连接与双后端回归检查；本版本的 Model Hub、V-Router 和 V-Scheduler 均声明为可选，PGV 为必需。
- **开发数据库对齐 PostgreSQL 17** — 本地开发默认镜像对齐 PGV `0.0.49` 的 `pgv:amd_17_20261015` / `pgv:arm_17_20261015`；根目录 Compose（容器编排配置）的数据库镜像更新为 `paradedb/paradedb:v0.25.11-pg17`，健康检查通过网络端口探测。旧 PostgreSQL 16 数据目录不能直接复用，需逻辑备份迁移或使用新目录；脚本不自动迁移或清空旧数据。详见 [本地开发镜像替换](docs/local-dev/README.md#postgresql-镜像替换)。
- **证书安装阶段采用配置镜像源** — 后端镜像在首次安装证书前即应用 `APK_MIRROR_ARG`，避免该阶段仍访问默认软件源而阻断构建。

### 模型与运行

- **接入统一与旧模型后端** — 新增 `HYBRAG_MODEL_BACKEND=auto|scheduler|model-hub`；本版本自动模式优先探测统一模型服务，否则选择旧后端，一次只选择一套。统一模型使用 `v-scheduler/ollama-<role>/<name>` 标识，推理失败不跨后端回退；自定义 `HYBRAG_BUILTIN_MODELS_YAML` 保持由管理员维护。独立发现两套服务及纯云启动兼容在 `0.1.71` 补齐，当前配置见 [模型后端迁移](docs/model-backend-migration.md)。
- **旧链路要求已发布的网关模型** — 旧 Model Hub 经 V-Router 的 `/v1` 接口调用 `model-hub/<name>`，启动时使用旧网关凭据检查选定模型是否全部出现在 `/v1/models`；路由、鉴权或模型缺失时拒绝启动，不回退原生 Ollama 端口。无显式版本后缀的模型名称补齐 `:latest`，避免目录标识不一致。

### 安全与权限

- **后台推理应用身份绑定** — 新增 `/api/v1/scheduler/gateway-binding`，仅接受经 VOS 用户信息接口验证的启用状态 V-Scheduler 应用下发凭据；凭据以仅当前用户可读写的 `0600` 权限持久化，不进入模型数据库、浏览器响应或日志。四个内置统一模型逐次读取凭据以支持轮换，仅可请求固定网关的模型列表和推理接口，禁止重定向；损坏或不安全的绑定文件不会回退旧密钥。本版本使用旧网关别名，独立地址隔离见 `0.1.71`。

### 文档与验证

- **数据库升级证据与边界** — VOS 应用说明补充 PostgreSQL 17 的已有检索验证，以及用户反馈的 ARM（处理器架构）环境按先 PGV、后 HybRAG 顺序升级后的单文档问答结果；后者尚未核对运行日志和数据库实际版本，全量数据一致性、反向升级顺序与全新安装仍待验证。详见 [ARM VOS 顺序升级验证](README.md#arm-vos-顺序升级验证)。
- **API 文档补齐现有接口** — 接口说明补充系统模型目录读取、预览、发布及文档处理时间线，修正文档中的路径、鉴权声明与对象结构；本项不改变这些接口已有的运行权限。

## [0.1.67] - 2026-10-14

以下条目记录源码中已实现的变化；部署验证边界见本节“已知限制”。

### 新增

- **Seafile 数据源** — 新增兼容 Seafile Server 10.0.1 的 `api2`（Seafile v2）接口连接器，可选择资料库内的目录和文件并执行定时、增量、断点续传及源端删除对账；私网 API 或文件下载主机需加入用于限制服务端请求目标的 `SSRF_WHITELIST`，加密资料库不支持同步。
- **钉钉上传文件入库** — 钉钉数据源新增 `Settings.include_uploaded_files` 开关，默认关闭；开启后可同步 DOCX、PPTX、XLSX 和 PDF 附件，单个文件上限为 64 MiB（64×2²⁰ 字节）。存量数据源升级后仍保持关闭，避免意外下载、存储和向量化文件。
- **会话附件按需读取** — 智能体可通过 `read_file` 读取当前会话及其分叉继承的附件，无需沙箱；每条消息最多引用 5 个附件，直接放入上下文的附件单个不超过 2000 个估算 token（模型处理文字的计量单位），合计不超过 6000 个，大文件由智能体按需读取。详见 [VOS 用户指南](docs/USERGUIDE.md)。
- **系统用户管理** — 系统管理员可分页查看跨空间账号、创建用户、重置密码、调整系统管理员身份并启用或禁用账号；禁用会撤销该用户已有登录凭证，系统拒绝禁用当前管理员或最后一个活跃系统管理员。VOS 操作说明见 [用户指南](docs/USERGUIDE.md)。
- **MCP（模型上下文协议）无浏览器授权** — 服务新增 OAuth 2.0（第三方授权协议）接口 `POST /api/v1/mcp-services/:id/oauth/assertion`，允许当前用户提交 JWT Bearer 断言（用签名令牌向授权服务证明身份）获取访问令牌，供无法打开浏览器的客户端使用；外部授权服务须支持该断言授权方式，用户间的令牌和连接保持隔离。
- **嵌入聊天粘贴截图** — 网页嵌入渠道和绑定的智能体均允许文件上传时，访客可在输入框粘贴图片、预览后发送；支持 JPEG、PNG、GIF、WebP，每张不超过 10 MB、每次最多 5 张。
- **Docker 沙箱交互终端** — 使用 Docker 后端的沙箱可在聊天面板中打开交互式终端；其他沙箱后端不因本项获得该能力。
- **图片画廊来源筛选与连续浏览** — 知识库图片画廊可按来源文档筛选，并以瀑布流滚动加载后续图片。
- **MCP 新旧协议协商** — 内置 `/mcp/:endpoint_id` 同时接入 `2026-07-28` 与 `2025-11-25` 客户端，沿用原有令牌、工具白名单和知识库权限；外部 MCP 服务按对端独立协商，新版发现失败后尝试旧版初始化。忽略发现请求的旧服务最多增加约 5 秒探测等待。调用白名单外的工具现在返回 JSON-RPC（远程调用消息格式）错误 `-32602`，不再返回工具结果 `isError=true`，客户端需兼容该错误形状。
- **图片向量与相似度调试** — 模型调试面板可对支持图片输入的向量和重排模型上传图片，并比较查询与文字、图片候选的向量相似度；文档上传确认页可为本次处理覆盖图片向量开关，沿用知识库选择的向量模型。

### 优化

- **智能体工具配置与运行时对齐** — 编辑器按运行时实际注册的能力展示内置工具；`allowed_tools: []` 表示不启用内置工具，未设置或为 `null` 时使用默认工具。迁移会把旧版智能体的空列表转换为显式默认工具，保留升级前行为。
- **技能和 MCP 服务搜索** — 技能和 MCP 服务设置页新增搜索框，可筛选列表并清除关键词。
- **知识图谱视图聚焦** — 知识图谱（用实体和关系连接知识项的结构）的 Wiki（知识库中的结构化知识页面）视图可按主题分组聚焦、切换分组并显示或隐藏未关联页面；退出聚焦后恢复进入前的视角。
- **知识库描述生成预算可配置** — 新增 `KNOWLEDGE_BASE_PROFILE_MAX_TOKENS`，正整数覆盖描述生成的 token 预算，默认 `2048`；留空或值无效时使用默认值。
- **聊天欢迎语统一 Vivibit 品牌** — 简体中文和繁体中文首页欢迎语使用 `Vivibit 小助手`；英文使用 `Vivibit AI Assistant`，日文、韩文和俄文使用对应称呼。更新包含该变化的 `weknora-ui` 前端镜像后生效。
- **向量批处理与检索诊断** — Qwen3-VL 向量请求支持批量消息输入，模型目录中的对应预设将图片批次上限设为 5；候选去重减少重复相似度计算。检索与重排诊断记录使用 `diagnostics.retrieval.*` 和 `diagnostics.rerank.selection`，与实际模型调用区分；本次未作吞吐或延迟量化。

### 修复

- **数据源增量同步保护** — Notion 查询被服务端上限截断时不执行删除对账；语雀详情读取失败不推进相应同步游标；Feishu 限流增加共享节奏控制与重试；Feishu、GitLab、IMA 和 Notion 的重复分页游标会终止并报错。GitLab 源文件清空后也会清除旧的可检索正文。
- **索引批量失败不再伪装成功** — SQLite 索引行写入或复制、Elasticsearch `_bulk` 写入及 Qdrant/Milvus 关键词检索中的批量错误会返回失败，不再被吞掉或误报无匹配；Qdrant 复制使用服务端返回的 `next_page_offset` 翻页，Milvus 复制按映射分块读取源行，避免静默漏掉向量。
- **文档入库失败清理与重试** — 暂时性索引写入失败进入既有队列重试；存储配额检查失败时清理本轮已写入的分块，避免留下部分索引内容。
- **Wiki 表格更新防止丢行** — 智能体重写可能缩短原有表格时拒绝写入并保留原正文；删除源文档导致的行撤回仍可应用。
- **知识图谱查询标明截断并保留来源** — 结果在实体、关系或来源证据被截断时向智能体说明结果不完整，并保留关系方向和文档来源，避免把子图当作完整图谱作答。
- **EPUB 电子书与 PPTX 演示文稿内容关联修复** — EPUB 章节按书内目录顺序读取，预览保留内联图片；PPTX 回退解析保留图片与幻灯片的关联。
- **OCR 与结构化摘要失败不再保存为成功结果** — OCR（从图片识别文字）拒绝截断、重复填充或校验失败的输出，并记录提取失败；模型明确无可识别文字时保留 `no_text`。结构化摘要的 JSON（按字段组织的数据格式）截断、畸形或缺少有效摘要时进入失败与重试路径，不再把残片当作摘要；非空纯文本模板结果仍可保存。
- **聊天追问与会话连接隔离** — 同一会话只保留当前回答连接，替换或关闭旧连接不会中断新回答或其他会话；排队追问在消息成功保存后才算消费。
- **模型连接测试等待冷启动** — 模型编辑器的远程连接检查最长等待 90 秒，提示本地服务首次测试可能需要加载模型；模型端返回非鉴权类 `400` 时按可达处理，凭据错误仍显示失败。
- **历史会话选择隔离** — 恢复历史会话时，未保存的文件、标签、MCP 服务和技能选择会清空，避免继承其他会话的范围；只保留仍选中文件的知识库归属缓存，不改写用户默认设置。
- **引用原文入口与元数据保留** — 有文档标识但缺少分块标识的引用也可打开原文件；知识库问答的图谱和数据分析引用保留文档自定义元数据，引用高亮同步调整。流式回答中的引用标记完整出现，隐藏的文档标识和长链接不再拖慢正文显示节奏。
- **Markdown 编辑与显示** — Markdown（带格式标记的正文）答案编辑器修正列表退缩进后的光标、跨行选择边界和非空列表项的回车行为；聊天、文档预览和 Wiki 正文中的单个 `~` 按原文显示，双 `~~` 仍可表示删除线，外部链接保留新窗口打开行为。
- **文档分块与内嵌图片定位** — 表格子分块的起止位置排除补入表头的偏移，转义竖线不再被误计为新列；代码围栏内的标题不参与标题分块。HTML/MHTML（网页及网页归档格式）转换保留空内联元素占用的空白，EPUB 图片优先按章节相对路径解析，AnyDoc（进程内文档解析引擎）的 EMF/WMF（Office 矢量图片格式）图片引用与存储扩展名保持一致。既有文档需重新解析才能获得新的分块和图片结果。
- **数据分析文件加载与查询** — CSV（以逗号分隔字段的表格文件）和 Excel 表加载失败后可重试，不再因已登记清理而跳过加载；XLSX 中只有样式的空工作表会跳过，只有表头或公式的工作表仍保留。SQL（结构化查询语言）列名修正不再改写字符串字面量和注释。
- **FAQ 克隆状态同步** — FAQ（常见问答条目）副本同步启用状态、标志和标签时，只更新这些字段，保留副本已有正文与索引状态。
- **Wiki 任务与链接失败可见** — 源文档查询暂时失败时保留待处理更新并返回可重试错误；重建链接遇到部分页面写入失败时返回失败数量，不把半成品报告为成功。未加载的反向链接可解析并展示页面标题。
- **MCP 工具结果完整传递** — 智能体可读取工具返回的内嵌文本资源、资源链接和 `structured_content`（按字段组织的工具结果）；重复的 JSON 文本结果只保留一次，工具失败仍保留结构化结果及失败状态。
- **MCP 连接恢复与目录校验** — 对端遗忘会话后会重新初始化连接，慢连接清理不再持有跨服务的共享锁。连接测试会报告已声明工具或资源目录的读取失败；资源目录完整分页读取，重复游标或超过 100 页时返回错误。显式禁用的新服务保持禁用，端点知识库选择包含已授权共享知识库。
- **向量存储连接与写入一致性** — Qdrant 的环境连接与索引配置统一读取，写入、删除及状态更新等待服务端完成，并接受并发创建的集合；Milvus 连接测试校验实际凭据和数据库，不再仅检查端口。Weaviate 索引复制遇到重复游标或查询错误时明确失败。
- **知识库视觉配置更新** — `PUT /api/v1/knowledge-bases/:id` 接受可选 `vlm_config`，未提供时保持原配置；更改视觉配置需要知识库设置权限，启用时校验托管视觉模型。请求不能写入旧版内联地址和凭据，避免绕过模型管理与请求目标校验。
- **克隆图片资源归属与回收** — 文档和 FAQ 克隆会登记源文件、正文资源及解析图片的文档归属；删除时同时读取资源目录中的引用，避免只按分块图片列表清理而遗漏资源。
- **沙箱恢复状态兼容** — Docker 文件操作遇到空闲回收导致容器消失时，按资源不存在处理以触发重新绑定；阿里云 E2B（远程沙箱服务）从快照创建时省略服务不接受的环境变量、挂载和内存覆盖。模板状态 `in_progress` 显示为构建中，不再误判为失败。
- **技能安装验证范围** — 验证技能脚本时跳过任意层级的 `.venv/` 和 `node_modules/` 依赖目录，避免依赖脚本过多导致命令参数超限；依赖本身仍由依赖验证步骤检查。
- **网页搜索范围与数量** — Metaso 的文档、学术、播客、视频和图片范围读取各自结果数组，不再只读取网页结果；`web_search` 的数量说明跟随配置上限，超出上限时截取并向智能体说明，小于 1 仍拒绝。
- **图谱抽取拒答与截断区分** — 异步抽取遇到自然结束的纯文本拒答时记录 `model_declined` 并跳过；输出截断、断流或缺少结束原因仍进入失败与重试路径，初始化试抽取和查询侧调用继续报告失败。
- **问答检索范围说明** — 摘要意图不再触发知识库召回；召回候选经重排、合并或 `FILTER_TOP_K` 截取后，在模型上下文中说明只展示了候选子集，避免把前几条片段当作知识库全部结果。
- **数据源校验与元数据更新** — 钉钉连接校验会继续寻找有权限的文档，不再因单个工作区不可读就判定整个来源失败；达到抽样上限时说明校验范围。Notion 正文读取失败保留同步游标；RSS（订阅内容源）的增量指纹纳入标题和链接，正文未变时也可更新这些信息。
- **即时消息附件保留** — 企业微信长连接中的图文混合消息将首张图片与文字说明一并交给问答，云之家附件下载可重试；自定义企业微信 `wss` 端点继续经过服务端请求目标检查。
- **智能体工具参数校验** — 字符串长度按 Unicode 字符计数，参数转换保留未修改数字的精度，枚举值按实际类型比较；数据分析工具接受合法的相邻带前缀 Python 字符串，不再误报引号错误。
- **智能体流与后台异常恢复** — 模型流建立阶段也受无输出超时约束，断流摘要不会保存为记忆检查点；MCP 预热和知识检索的后台异常会转为失败状态，不再导致整个服务进程退出。
- **文档处理状态与失败记录** — 已完成、失败、取消或被新解析取代的旧时间线阶段会关闭，避免永久显示进行中；队列失败记录按 Unicode 字符边界截断错误文本，避免中文被截成非法字节而无法保存。
- **腾讯 COS 的 S3 地址兼容** — 通过 S3（对象存储接口）驱动连接腾讯 COS（对象存储服务）时，`.myqcloud.com` 端点默认把桶名放在域名前，避免上传被拒绝；显式 `force_path_style=true` 仍优先，继续采用路径中的桶名。
- **文件读取分页预算** — `read_file` 将文件路径长度计入输出预算，避免长路径挤占正文空间而丢失分页内容；路径和元数据已超预算时明确报错，不返回误导性的续读位置。
- **编辑器未保存提示** — 智能体编辑器的初始化和模型参数归一化不再触发未保存警告；知识库解析引擎的加载或刷新只展示默认值，不自动修改已保存规则，实际编辑仍需保存。
- **上传大小提示对齐配置** — 知识库空状态和拖拽上传提示在六种语言中显示当前 `MAX_FILE_SIZE_MB`，避免沿用固定的旧大小说明。
- **韩文用户名提示** — 注册页的韩文说明与校验规则对齐，明确允许英文字母、数字、下划线和汉字，不再提示允许韩文字母。

### 模型与运行

- **图片向量检索** — 知识库可选择启用图片向量检索（将图片编码为可参与语义搜索的向量）；默认关闭，须同时启用多模态处理并使用支持图片输入的向量模型。支持图片输入的重排模型（按模型分数调整召回结果顺序的模型）可按图片本身评分；对话模型支持图片时，每次检索最多附带 3 张去重图片。已有文档需重新解析；扫描 PDF 页面不生成图片向量。详细配置见 [VOS 用户指南](docs/USERGUIDE.md)。
- **新增远程重排协议** — 模型目录新增 Cohere v2、Pinecone Inference 和 Hugging Face TEI（Text Embeddings Inference，文本向量推理服务）重排服务，可按对应厂商协议配置远程重排模型。
- **新增 Claude 与 WeMM 模型目录项** — 内置目录加入 Claude Opus 5.5、Sonnet 5.5、Haiku 5.5，以及 `tencent/WeMM-Embedding-2B`、`tencent/WeMM-Embedding-4B` 和 `tencent/WeMM-Embedding-9B` 图片向量预设；WeMM 另提供 Transformers（模型推理框架）服务脚本和部署说明。对不接受 `temperature` 的 Claude 模型不再发送该参数。
- **OpenRouter 思考参数兼容** — 历史默认 `thinking_control=none` 不再覆盖 OpenRouter 的原生思考参数编码，显式非默认配置仍优先。
- **工具调用轮次的模型兼容** — OpenAI 兼容聊天接口在仅含工具调用的助手轮次显式发送空 `content`，避免本地模型的聊天模板因字段缺失而拒绝请求。

### 安全与权限

- **智能体数据库查询遵循共享知识库授权** — SQL 查询按每个已获授权的共享知识库及文档范围注入条件，避免借助共享知识库查询读取未授权租户数据。
- **MCP 只读工具风险标记** — 对外 MCP Server（供外部工具客户端连接 WeKnora 功能的服务）端点将只读工具标记为非破坏性和幂等（重复调用不改变已有结果）；写入工具仍标记为破坏性操作，外部客户端可据此显示准确的操作提示。
- **连接器响应体受大小限制** — 语雀、Notion、IMA 和飞书连接器的单个 JSON 响应上限为 16 MiB（16×2²⁰ 字节）；远程图片下载遵循文件大小上限。超限按错误处理，不把截断内容当作完整文档入库。
- **MCP 授权凭据与时区隔离** — 动态注册返回的客户端密钥会保留供换取和刷新令牌使用；授权完成或撤销只清理对应用户的连接，不中断其他用户。令牌过期时间按 UTC（统一时间基准）保存和返回；`000140` 将旧无时区值按 UTC 转换，历史进程在其他时区写入的偏移值不会自动纠正，需重新授权或刷新令牌。
- **请求日志有界读取** — 访问日志只读取受限的请求体前缀，其余内容继续交给业务处理，避免鉴权前将整个大请求缓存进内存；这项调整不改变各接口自身的上传或请求大小限制。
- **渠道会话管理权限** — 当前空间管理员可从网页控制台管理该空间的 API、嵌入和即时消息渠道会话，包括修改与批量删除；普通成员和 API Key（接口访问密钥）不因此获得其他用户会话的管理权限。

### 已知限制

- **VOS 端到端验证待完成** — VOS 用户指南记录了相关本地回归验证；系统用户管理的 VOS 登录端到端验证，以及真实模型部署中的图片召回、图片重排和回答效果仍待验证。
- **旧数据库扩展与迁移边界** — VOS 的共享 PGV 保持 PostgreSQL 16 和 `pg_search` `0.22.6`；服务器未提供新扩展包时，`000137` 跳过升级并记为已执行，之后更换扩展包仍需管理员手工升级。旧扩展下的实际部署负载及新版前端欢迎语的部署显示尚未在本次审计验证。

## [0.1.65] - 2026-10-12

### 重点变化

- **通用 Ollama rerank 接入** — rerank（对召回候选重新评分排序）使用 ictrek Ollama 的 `/v1/rerank` 和标准 `query/documents` → `results` 协议；移除 `/api/embed` 第一维评分适配。默认模型行使用 `provider=generic` 和 `score_scale=probability`（按概率解释分数），已有 Ollama/local rerank 行仍可接入。
- **知识库图片画廊与按需 OCR** — 知识库新增画廊视图，支持搜索、属性筛选、排序、翻页和全屏查看；开启 `image_attrs_enabled` 后，VLM（理解图片的视觉语言模型）在生成描述时同步观察 `contain.text` 和 `contain.data_visual`，再由 `image_actions` 决定是否追加 OCR（识别图片中的文字）。默认仍保持原有的描述加 OCR 行为；历史图片若需属性筛选，需重新处理文档。
- **引用直达原文** — 点击知识库引用可打开原始文件并定位高亮，覆盖文字或扫描 PDF、Word、PPT、Excel/CSV、Markdown/TXT/EPUB 和带分段时间的音频；新入库分块保存 `source_locators`，旧文档继续按文字回退定位，重新解析后可获得精确位置。同步修复了重叠 PDF 文本、片段化 Markdown、表格高亮、文档预览启动失败以及历史会话引用浮层初始化。
- **统一检索与 rerank 语义** — 页面问答、Agent（可调用工具的智能体）`search_knowledge`、`POST /knowledge-search` 和 `POST /knowledge-bases/:id/hybrid-search` 共用同一套 rerank、分数归一化、MMR（兼顾相关性与内容差异的候选选择）去重和降级逻辑；两个 API 可控制召回阈值和 `rerank` 对象，并通过 `meta.rerank` 返回模型、阈值、候选数和降级原因。候选与返回上限统一约束为 200，模型加载或调用失败时按召回顺序返回；未配置 `request_timeout_seconds` 时，重排调用默认超时为 60 秒。
- **系统管理员模型目录** — 「设置 → 系统管理 → 模型目录」可编辑、预览、发布、恢复和导入导出模型目录覆盖；读取和发布使用 `GET/PUT /api/v1/system/admin/model-catalog`，预览使用 `POST /api/v1/system/admin/model-catalog/preview`。更新使用版本和部署基线检测冲突，其他实例约 5 秒内同步。控制台不接受凭据、请求头、`base_url` 或环境变量展开，这些仍由部署配置管理。

### 新增

- **台湾繁体中文** — 主界面和嵌入聊天新增 `zh-TW`，采用台湾用语；`zh-Hant`、`zh-HK`、`zh-MO` 等繁体语言标记映射为 `zh-TW`，后端语言校验也接受该值。
- **保留模型标识的配置复制** — 新增 `POST /api/v1/models/:id/copy`，Admin（管理员）及以上角色可复制当前工作空间的非内置模型；副本只改 `display_name`，保留上游模型 `name` 和服务端已存凭据。已就绪的本地模型不再重复下载，前端生成符合长度限制的副本展示名。
- **跨知识库 Wiki 搜索** — 新增 `POST /api/v1/wiki-search`，可在多个自有或共享知识库中按标题、`slug`（页面路径标识）、摘要和正文排序，返回 `match_snippet`；要求 Viewer（只读角色）及 API Key `retrieve`/`full` 权限，并在检查 Wiki 开关前完成每个知识库的访问授权。

- **Confluence 子树和私有图片同步** — Confluence 数据源可选择页面子树并解析需鉴权的附件图片，单页内联图片总量限制为 50 MiB（1 MiB 为 2²⁰ 字节）。Server/Data Center 返回重复尾页链接时会停止无穷翻页，并逐页确认未列出内容后才执行删除对齐，避免部分列表误删文档。
- **语雀目录层级同步** — 语雀数据源新增 `folder_mode=toc` 和 `toc_only`，可按「书名/分组/文档」保留目录层级；新建来源默认启用 TOC（目录层级），已有来源保持 `folder_mode=none`。切换模式后需执行一次全量同步；`toc_only` 只停止新的同步入库，不自动删除已存文档。

### 优化

- **自动语言跟随** — VOS 内的自动模式优先采用平台语言，通过 `window.vos_platform.getState()` 和 `locale-change` 广播接收初始值与切换；延迟快照不会覆盖更新的事件。手动选择不被平台覆盖，切回自动采用最近的平台语言；缺少平台语言或独立打开时回退到浏览器首选语言、部署默认和 `zh-CN`。切换不刷新页面，保留未保存输入；旧 VOS 继续兼容同源语言存储。详见[语言设置与验证边界](README.md#安装与升级)。
- **回答语言跟随当前问题** — 问答和 Agent 提示词优先遵循用户显式语言要求，其次采用最新问题的主要语言，无法判断时才使用配置默认；来源文档和历史回答不改变该优先级。旧保存模板中的固定语言规则在渲染时兼容替换，自我介绍的角色名称也按回答语言生成。
- **查询扩展减少重复向量调用** — 初次召回不足时，本地生成的查询变体只执行关键词检索，不再逐个计算向量并重复语义召回；关闭关键词匹配时跳过扩展。
- **数据源调度与失败边界** — `sync_schedule` 统一按含秒的六段 cron（定时执行表达式）校验，空字符串表示仅手动同步；无效创建、更新或恢复请求返回 `400` 且不改写已存调度。Notion 资源发现失败会中止增量同步，飞书 Wiki 重复分页 token 会明确报错，RSS 响应超限时不再静默截断正文。
- **Wiki 积压并发清理** — 标准 Redis 模式会按 `ingest_max_inflight` 补充 Wiki 后续批次，同时用每知识库预留和恢复探针限制排队、运行与重试中的后续任务，避免积压退化为单批串行或并发完成时重复放大队列；Lite（轻量运行模式）和限流路径仍保持单后续任务。
- **前端资源刷新一致性** — 知识库、Agent、组织和模型等列表取消 60 秒 TTL（缓存有效期），改为进行中请求去重、显式失效和旧响应隔离；`/auth/me` 与系统信息的重复请求同步收敛。`/platform/settings` 只挂载一个设置弹窗，避免双弹窗之间出现旧数据。
- **自动会话标题** — 标题生成会把首条问题当作数据而非指令，并移除思考块、Markdown 表格、标题、列表和链接格式；输出仍不合法时使用用户问题的 30 个 Unicode 字符作为纯文本标题。Web 问答等待回答完成后再调用标题模型，避免抢占单并发模型；标题调用限制为 10 秒、最多 64 token（模型输出单位），超时或无可用标题时保存兜底标题。
- **应用内帮助链接** — 模型、沙箱、API、图谱和系统信息等页面的帮助入口改为打开已发布文档站，不再直接展示 GitHub 原始 Markdown；测试会校验每个页面和锚点存在。

### 修复

- **跨存储检索排序** — RRF（按各检索列表名次融合结果）改为逐列表排名并归一化融合分，关键词分也按各自列表缩放，避免返回顺序或不同分数尺度压低有效候选。OpenSearch、Weaviate 和 Milvus L2 路径同时换算向量分与阈值，按余弦相似度比较；相关排序和阈值命中可能与旧版本不同。
- **FAQ 混合范围过滤** — 检索范围包含 FAQ（常见问答条目）库时，即使主库是文档库或 FAQ 来自共享库，也会执行反例问题过滤；主库为 FAQ 时按每个向量列表是否满额决定扩大召回，并沿用首轮融合规则。
- **快速问答结尾重复** — 快速问答不再重复追加流的最后片段，保存历史和 `final_content` 与实际回答保持一致。
- **空问题生成结果** — 模型没有返回可用问题时明确报错；全部分块生成失败时返回任务错误，部分失败记录为 `partial_failure`，不再把空结果记作成功。
- **摘要目标语言优先级** — 摘要生成提示词要求所有生成字段优先采用目标语言，包括主题标签和文档类型，避免源文档语言覆盖指定语言。
- **Agent 文档内搜索续读** — `read_document` 的关键词匹配结果达到数量或输出长度上限时返回 `next_offset`，可用同一查询继续读取后续匹配，不再只能通过整份文档翻页查找遗漏片段。
- **Agent 图谱查询** — `query_knowledge_graph` 实际读取图谱实体、关系和来源分块，再以文字检索补充证据，图谱专用知识库不再只走普通文本检索。文档或标签范围会过滤来源证据和关系；单次最多使用 8 个实体查询词、每知识库 10 个证据分块，并返回最多 30 条关系。
- **未知问答意图回退** — 模型返回的意图忽略大小写和分隔符差异；无法识别的标签按需要检索处理，避免意外跳过知识库后直接生成无检索依据的回答。
- **仅上传图片或文件的问答** — 内联图片或附件带有上传数据时允许空 `query`，使用当前语言的默认问题调用模型，并保留用户原本的空文字；历史回放不会丢掉这一轮。仅有图片 URL、预上传附件 ID 或完全空的请求仍返回 `400`。
- **合同 PDF 预览资源回收** — 切换文档、过期加载和离开页面时通过 PDF 加载任务清理资源，避免预览组件调用不匹配的销毁方法。
- **AnyDoc 解析完整性** — AnyDoc（进程内文档解析引擎）从 `0.1.9` 升至 `0.2.4`，保留公式和复选框节点；需要 OCR 的混合或扫描 PDF 回退到 builtin，缺少回退解析器时明确失败。图片 Markdown 和图片资源复用一次解析，减少重复处理。
- **FAQ 条目清理与校验** — FAQ 写入前会去除问题和答案首尾空白，丢弃空值并去重；仅含空白的答案现在会被拒绝，不再把无效或重复内容保存到知识库。
- **会话知识库范围恢复** — 切换到未保存知识库范围的历史会话时会清空上一个会话的选择，避免继续把过期的 `@KB` 范围发送给服务端；离开会话后仍恢复浏览器级默认选择。
- **表格摘要任务边界** — 已删除或不属于任务租户的文档不会继续执行遗留的表格摘要任务；模型返回空摘要时改为明确失败并进入既有重试路径，不再保存空的表格或列说明。
- **数据源内容与增量同步** — 钉钉同步会记录跳过、失败和尚未建模的块类型，并保留列表、代码、附件及可读的未知块内容；GitLab 按提交快照比较强推或重置后的变化；飞书云盘重复分页 token 会终止并报错；Notion 页面清空后会覆盖旧正文，IMA 笔记清空后以标题覆盖旧内容；RSS 全文抓取失败后会在下次同步重试。
- **Lite 关键词字面匹配** — SQLite 查询为 `%`、`_` 和 `\` 补齐显式 `ESCAPE` 语义，文档、知识库、标签、租户、成员、会话及分块/FAQ 搜索不再静默漏掉或扩大包含这些字符的关键词；PostgreSQL 保持相同字面匹配行为。
- **Embed Host context 追问** — 嵌入渠道调用 `WeKnora.setContext` 后，追问建议可识别合法的 `[Host context]` 信封，不再因归因文本不完全相等返回 `400`；生成回答期间未实际发送的点击也不会污染下一条消息。
- **本机 Skill 密钥标签** — 环境变量设置中的本机 Skill 密钥卡片使用当前语言的“本机”标签，不再在其他语言界面显示后端原始配置名称。
- **文档处理任务恢复** — 重新解析会取消被取代尝试的排队任务，并在事务中完成子任务计数与阶段推进；入队失败、短暂读写错误、图片计数、Wiki 模型创建失败和 worker panic 都会进入重试或明确失败，减少文档长期停在 `processing` / `finalizing`。
- **Excel 容错解析** — builtin 和 MarkItDown 路径会在 openpyxl 加载前修复 `xl/styles.xml` 中缺少 fill 定义的工作簿，并移除 openpyxl 无法解析的数据验证范围；单元格文本不受影响，修复失败时保留原文件的原始错误。
- **JSON 上传提前校验** — 上传或替换的非法 `.json` 文件在 HTTP 边界直接返回本地化 `400` 错误，不再创建后经过多轮异步解析才失败；数据源和 IM 入库仍保留异步失败语义。
- **向量索引复制与并发创建** — Elasticsearch v7/v8 `CopyIndices` 保留向量、`SourceID` 和启用状态，不再把生成问题行或禁用行复制为不可检索数据；Weaviate 多 worker 竞态创建同名 class 时会重新查询并继续，不再使整份文档失败。
- **Agent 工具调用恢复** — 并行工具发生 panic 时转换为失败的 tool result，不再崩溃服务器；合并相邻 assistant 历史消息时保留 `tool_calls`，避免孤立 tool 消息使 OpenAI 兼容端点返回 `400`。
- **对象存储路径与飞书图片降级** — S3、COS、KS3、OBS、OSS、TOS 和 MinIO 服务接受规范的 `storage://` 路径；飞书回复中无法解析的 `resource://` 图片降级为纯文本，不再导致整张消息卡片更新失败。
- **表单弹层间距** — 邀请、分享链接、创建用户、重置密码和修改密码弹层恢复内边距、宽度和超高滚动，避免表单紧贴边框或主按钮被裁切。

### 打包与部署

- **文档生成语言默认跟随请求** — AMD64、ARM64 打包模板将 `WEKNORA_LANGUAGE` 默认值改为空，摘要和问题生成采用 `Accept-Language`（请求中的语言偏好），缺少该头时回退到 `zh-CN`；显式非空配置仍优先。安装配置新增对应语言项，需重新打包并升级、重建后端容器后生效，已有生成内容不自动改写。
- **ARM64 沙箱构建** — 沙箱镜像按目标平台选择基础镜像，并校验系统与目标架构一致，避免将 AMD64 文件系统误标为 ARM64；Cube 变体也校验 `envd`（沙箱命令服务）的架构。ARM64 Cube 仍要求原生 KVM（内核虚拟机）环境。
- **镜像迁移验证等待数据库就绪** — `build_image.sh` 的迁移检查改为通过 PostgreSQL TCP 端口探测就绪，避免初始化阶段的临时 Unix socket 服务被误判为可用后过早执行迁移。
- **新功能数据库迁移** — PostgreSQL 新增 `000133_model_catalog_config`、`000134_embeddings_knowledge_chunk_index`、`000135_chunk_images` 和 `000136_chunk_source_locators`；SQLite 新增 `000041_model_catalog_config`、`000042_chunk_images` 和 `000043_chunk_source_locators`。升级部署需确保对应 `up` 迁移执行成功，否则模型目录、画廊或精确引用定位不可用。

### 模型与运行

- **显式零温度参数（部分落地）** — Completions、Responses、Anthropic 和 Gemini 请求构造器在 `TemperatureSet=true` 时会发送 `temperature=0`；厂商不支持温度、固定温度或思考模式的限制继续生效。当前业务调用尚未设置该标记，不能据此认为界面或 Agent 中配置的零温度已生效。
- **Rerank 与思考等级兼容** — 阿里云 `qwen3-rerank` 恢复使用 DashScope 原生 rerank 协议并重新出现在选择器中；仅支持布尔思考开关的通用模型只展示 `off` / `auto`，显式声明 `supports_reasoning_effort` 的模型才展示分级档位，并将 `reasoning_effort` 实际写入请求。恢复旧配置 `thinking_control=think` 的 `think:true/false` 和 `thinking_control=reasoning_effort` 的 `medium/none` 行为，未指定开关时不发送；VOS 默认 QA（问答模型）/VLM 使用后者。
- **模型限流重试** — Agent 对 `429` / `503` 响应同时支持秒数和 HTTP 日期格式的 `Retry-After`，按其与线性退避的较大值等待，并将服务端建议限制在 30 秒内，减少仍处于限流窗口时耗尽重试。
- **上下文压缩取消语义** — 摘要流因请求取消而关闭时会返回取消错误，不再把空摘要当作成功 checkpoint 保存；供应商错误、自然结束和原有停滞重试语义保持不变。
- **中断流识别与 SDK SSE 解析** — Completions、Responses 和 Gemini 流在没有 finish reason（结束原因）就结束时会标记为不完整并返回流错误，不再把半截回答存为完成；重试按结构化 HTTP/传输错误分类且可响应取消。Go client 同时按 SSE（服务器推送事件）规则合并多行 `data:` 并忽略空帧。
- **MCP 连接有界关闭** — 服务停止时会注册并并发关闭 MCP（模型连接外部工具的协议）连接，且设置总时间边界，避免远程 session 留待超时或串行断开阻塞进程退出。
- **信号关闭资源回收** — `SIGTERM` / `SIGINT` 关闭会在同一 `server.shutdown_timeout` 内划分连接排空和清理预算，并继续执行 BrowserSkill、沙箱、IM、任务池和 Langfuse 等清理钩子，避免监听器竞态触发 `os.Exit(1)` 后跳过回收。

### 安全与权限

- **邀请注册档位与升级动作** — 密码注册新增 `auth.registration_mode=invite_register`，只有有效邀请链接允许新用户注册；`self_serve` 保持公开注册。`invite_only` 现在同时禁止公开和邀请注册，邀请仅供已有账号加入空间；此前依赖邀请创建账号的部署需切换为 `invite_register`，历史 `DISABLE_REGISTRATION=true` 仍对应禁止注册。
- **登录令牌持久化失败** — access token 或 refresh token 保存失败时登录返回错误，不再返回下一次请求就无法使用的令牌；令牌查询失败报告基础设施错误，不再误报已撤销。
- **GitLab 下载体积边界** — 普通 API JSON 响应限制为 16 MiB，compare 响应为 128 MiB，单个原始文件为 512 MiB；超限返回错误，不再无界读入或把截断内容入库，base64 文件回退也设有响应上限。
- **共享 Agent 本地浏览器归属** — 共享空间 Agent 的 `local_browser` 从当前调用者而非 Agent 所有者解析设备范围，已与调用者配对的浏览器不再误报未配对，且仍不跨用户控制设备。
- **LLM 调试日志路径限制** — LLM（大语言模型）日志中来自 `X-Request-ID` 的文件名只保留安全标识符，阻止 `../` 选择日志目录外的路径；含完整 prompt（模型输入）的记录以 `0600` 写入 `0700` 目录。
- **Embed 签名密钥诊断** — 启动时会检测可用的 `SYSTEM_SIGNING_KEY` 并输出 `[startup-env]` 警告，Embed session 缺少密钥时的 `503` 错误也会指明配置项，便于升级后识别已失效的示例 `SYSTEM_AES_KEY`。

### 文档与验证

- **上游同步兼容检查** — [上游同步指南](docs/upstream-sync.md)增加合并前固定提交、本地定制行为与测试迁移核查，以及思考参数从配置到请求的回归要求；自动发现全部定制和阻断回归的专用检查仍未实现。

- **对象存储传输边界** — S3、COS、KS3、OBS、OSS 等对象传输不再受 30 秒整请求超时限制，连接建立、响应头、探测和后台任务分别设置边界；KS3 保留调用方上下文并仅在真实 404 时创建桶。存储路径规范化不再把后端作用域误当作对象路径的一部分。
- **IMA 与 BrowserSkill 稳定性** — IMA 子目录遍历使用列表响应中的媒体 ID；BrowserSkill 重新对齐补丁并使用原生会话生命周期和导航响应截止时间。
- **技能版本升级** — 过期技能可从技能目录、沙箱技能面板和 Agent 编辑器升级；升级过程中继续提供上一个已就绪版本，升级失败或停止时不将技能下线，也不会用重试操作回写目录定义。

### 修复

- **模型调用和文档解析错误处理** — 远程嵌入服务重试耗尽后返回真实错误而不是 `(nil, nil)`，DashScope 多模态向量按响应中的 `index` 写回批次位置；知识库自定义指令不再污染 OCR 提示词；PDF 默认继续使用内置解析器；聊天模型错误不会丢失 Ollama 代理配置。
- **建议问题去除当前问题** — 模型生成的建议和知识库候选均会按规范化文本过滤与当前问题完全相同的内容；知识库候选可由后续候选补位，模型生成的建议过滤后可能少于配置数量。
- **XMind 上传校验** — 前端附件和后端临时文档白名单加入 `.xmind`，文件在解析引擎发现前不再被误判为不支持。
- **共享工作区图片恢复** — 回答完成并持久化后，在权限可用时重试受保护图片加载，覆盖普通、快速时间线和 Agent 会话，避免流式结束后图片继续显示失败。
- **合同审查 PDF 证据定位** — 对同一位置的重复 PDF 文本去重后再匹配引用，避免视觉叠加文本使合同审查证据无法定位。
- **缩放状态下的操作引导定位** — 浏览器或根页面缩放时，高亮区域和引导浮层保持对齐。
- **会话标题失败降级** — 标题模型不可用、调用失败或返回空标题时，使用首条问题生成并持久化兜底标题，同时优先使用本轮实际对话模型。

### 打包与部署

- **VOS App Store 发布通道** — VOS 发布工作流以 `channel=stable` 发布应用包；遇到不接受该字段的旧接口时回退到无通道参数的请求。
- **迁移版本冲突** — 上下文检查点迁移固定为 PostgreSQL `000105`，智能档案镜像相关迁移调整为 PostgreSQL `000126`–`000129`、SQLite `000033`–`000036`，避免重复版本导致 `golang-migrate` 无法启动或升级。
- **开发环境健康检查** — `docker-compose.dev.yml` 的数据库健康检查改为连接配置中指定的数据库，而不是固定使用默认数据库名。
- **大陆环境构建与缓存复用** — APT 默认使用 Aliyun 镜像，BrowserSkill 下载增加备用源，Cargo 支持 RsProxy 回退；Docker 构建复用 npm、pnpm、Cargo 和 Go 缓存，并延后易变版本层，减少重复构建下载。

### 模型与运行

- **模型协议、目录与厂商能力统一** — 对话、embedding、rerank 和 ASR 请求按协议包、`internal/models/catalog` 和厂商声明分层，增加基于厂商文档的 wire/golden 校验并修正多家厂商能力事实。`extra_config.api` 作为协议选择器且非法值会被拒绝；未设置 `api_version` 的 Azure 行使用 `/openai/v1`，官方 `api.openai.com` 请求使用 Responses 协议；rerank 的分批、分数标度和截断按厂商能力执行，`qwen3-rerank` 的不匹配配置在构造阶段拒绝；ASR 目录覆盖文档已声明该能力的厂商。Wiki taxonomy embedding 和 WeKnoraCloud embedding 保留批处理及并发限制。

### 安全与权限

- **跨工作区共享边界** — 预签名预览、知识库初始化、模型/存储配置、Wiki 写工具、嵌入和 MCP 范围均按资源所属工作区和共享权限校验；共享知识库响应不再携带存储或 VLM 凭据，自己的 Agent 优先于同名共享 Agent，匿名嵌入请求不能自选知识库、模型或问题来源；只读共享知识库隐藏写操作。共享 Agent 的 Skill/MCP 选择器读取资源所属工作区，MCP 响应使用收窄字段；沙箱固定配置同时记录所属工作区，删除、终端、桌面和分叉路径可正确解析借用的沙箱。
- **KS3 重定向 SSRF 防护** — 恢复 KS3 客户端的安全重定向策略，重定向目标继续经过 SSRF 检查，并避免把请求签名带到跨主机目标。
- **API Key 操作审计** — 知识库活动记录保存并展示发起操作的 API Key 名称，同时不把异步任务重新授权为该 Key。

### 已知限制

- **数据库驱动范围** — 运行时的 `DB_DRIVER` 当前只接入 PostgreSQL 和 SQLite；仓库中的 `migrations/mysql/` 仅作未接入的参考脚本，不能据此声称已支持 MySQL。
