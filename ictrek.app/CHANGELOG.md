# VOS HybRAG Changelog

记录 VOS HybRAG 应用的可验证变化。

## [Unreleased]

### 重点变化

- **统一 Agent 知识检索入口** — 将重叠的检索工具收敛为 `search_knowledge`、`read_document` 和 `list_documents`；支持 `hybrid`、`semantic`、`keyword` 模式、文档内关键词查询、分页和上下文读取，并保留旧工具名的运行时兼容映射。绑定知识库会在回答前先检索，建议问题会携带并校验来源文档。
- **智能档案解析与知识库镜像解耦** — 解析、OCR 和托管知识库镜像分别持久化状态；档案可在解析结果保存后展示，镜像失败只重试镜像任务，页面显示阶段进度，取消、重启恢复和并发清理路径均有明确状态。托管镜像知识库保持只读，相关操作通过智能档案入口完成。详见[智能档案文档](docs/smart-archive.md)。

### 新增

- **产物库与生成文件删除** — 新增 `GET /api/v1/artifacts` 产物库，按会话和源路径展示文件最新版本，支持关键词、文件类型筛选、分页、预览、下载和跳转会话；仅 web 会话进入该列表。会话内和产物库均可删除生成文件，删除采用 `deleted_at` 软删除并按资源引用计数回收字节，保留旧链接定位和并发写入安全。涉及 PostgreSQL `000103`、SQLite `000023` 产物表及 PostgreSQL `000125`、SQLite `000032` 删除标记迁移。
- **知识库文件上传任务面板** — 批量上传改为全局队列，提供整体进度、字节数、预计剩余时间、解析状态、取消、重试、问题筛选和文档入口；上传后会继续跟踪解析完成状态，并在页面离开前提示仍在运行的任务。默认并发为 3 个文件，同一知识库的同大小文件不会并行重复提交；未显式设置超时时，上传超时会按请求体大小计算。
- **会话原地回滚** — 新增 `POST /sessions/:id/rewind`，可回滚到用户或助手消息并截断其后的会话内容；存在可达检查点时同步重置沙箱工作区。发送中、无检查点或工作区已变化时返回冲突并保持会话数据，回滚与发送互斥，成功后重新加载历史并在用户消息处预填原问题。
- **已保存答案 Markdown 编辑器** — 保存答案时自动移除内部 `<kb>` 引用标签、集中展示引用文档并保留 web 链接；编辑器支持编辑/分栏/预览、全屏、常用 Markdown 快捷键、列表续写、未保存确认和字符/行数统计。

### 优化

- **Agent 历史与上下文压缩** — 压缩摘要持久化到消息的 `context_checkpoint`，后续轮次和分叉会从最近检查点继续；Agent 历史按模型窗口和校准后的 token 估算加载，快速问答仍保留原有轮数上限。
- **流式回答恢复** — 重放已保存的回答流时合并同一片段的连续事件，减少刷新或重新进入会话时的事件数量；新一轮回答不再继承上一轮文本。工具执行失败按 `response_type=tool_result` 返回，使 Agent 可以恢复；达到 completion 上限时结束当前轮次，并在 SSE、历史重建和界面中保留截断标记。
- **聊天、知识库和资源界面** — 优化知识库文档浏览、标签编辑、聊天面板间距、滚动、问题大纲、引用和产物展示；统一资源图标、共享筛选状态和会话分叉入口，并恢复聊天导航与引用初始化。
- **解析时间线** — 失败卡片优先展示具体阶段和后端错误，重试入口靠近失败原因；时间轴刻度和偏移保持在图表范围内，失败后未执行的阶段标记为未运行。
- **知识处理稳定性** — 所有解析器在分块前统一规范内联 HTML 表格，并限制 Markdown 链接/图片保护范围，避免超长或跨段保护区域阻塞分块；嵌入模型解析失败和多模态任务入队缺口会落盘为明确失败，不再长期停留在 `processing`；任务队列优先处理失败次数较少的任务；临时文件写入失败会清理文件；Qdrant 中不存在目标维度集合时删除向量按空集合处理。
- **Wiki 与知识图谱结果** — 去重提示同时比较名称和显式别名并拒绝仅凭歧义缩写合并；跳过不明确的单汉字自动链接，扩大实体抽取输出预算；缺失历史快照时以可用内容降级展示；Reduce 阶段引用的文本块会带入启用的图片描述/OCR 信息。
- **对象存储传输边界** — S3、COS、KS3、OBS、OSS 等对象传输不再受 30 秒整请求超时限制，连接建立、响应头、探测和后台任务分别设置边界；KS3 保留调用方上下文并仅在真实 404 时创建桶。存储路径规范化不再把后端作用域误当作对象路径的一部分。
- **IMA 与 BrowserSkill 稳定性** — IMA 子目录遍历使用列表响应中的媒体 ID；BrowserSkill 重新对齐补丁并使用原生会话生命周期和导航响应截止时间。
- **技能版本升级** — 过期技能可从技能目录、沙箱技能面板和 Agent 编辑器升级；升级过程中继续提供上一个已就绪版本，升级失败或停止时不将技能下线，也不会用重试操作回写目录定义。

### 修复

- **模型调用和文档解析错误处理** — 远程嵌入服务重试耗尽后返回真实错误而不是 `(nil, nil)`，DashScope 多模态向量按响应中的 `index` 写回批次位置；知识库自定义指令不再污染 OCR 提示词；PDF 默认继续使用内置解析器；聊天模型错误不会丢失 Ollama 代理配置。

### 打包与部署

- **VOS App Store 发布通道** — VOS 发布工作流以 `channel=stable` 发布应用包；遇到不接受该字段的旧接口时回退到无通道参数的请求。
- **迁移版本冲突** — 上下文检查点迁移固定为 PostgreSQL `000105`，智能档案镜像相关迁移调整为 PostgreSQL `000126`–`000129`、SQLite `000033`–`000036`，避免重复版本导致 `golang-migrate` 无法启动或升级。
- **开发环境健康检查** — `docker-compose.dev.yml` 的数据库健康检查改为连接配置中指定的数据库，而不是固定使用默认数据库名。

### 模型与运行

- **模型协议、目录与厂商能力统一** — 对话、embedding、rerank 和 ASR 请求按协议包、`internal/models/catalog` 和厂商声明分层，增加基于厂商文档的 wire/golden 校验并修正多家厂商能力事实。`extra_config.api` 作为协议选择器且非法值会被拒绝；未设置 `api_version` 的 Azure 行使用 `/openai/v1`，官方 `api.openai.com` 请求使用 Responses 协议；rerank 的分批、分数标度和截断按厂商能力执行，`qwen3-rerank` 的不匹配配置在构造阶段拒绝；ASR 目录覆盖文档已声明该能力的厂商。Wiki taxonomy embedding 和 WeKnoraCloud embedding 保留批处理及并发限制。

### 安全与权限

- **跨工作区共享边界** — 预签名预览、知识库初始化、模型/存储配置、Wiki 写工具、嵌入和 MCP 范围均按资源所属工作区和共享权限校验；共享知识库响应不再携带存储或 VLM 凭据，自己的 Agent 优先于同名共享 Agent，匿名嵌入请求不能自选知识库、模型或问题来源；只读共享知识库隐藏写操作。共享 Agent 的 Skill/MCP 选择器读取资源所属工作区，MCP 响应使用收窄字段；沙箱固定配置同时记录所属工作区，删除、终端、桌面和分叉路径可正确解析借用的沙箱。
- **KS3 重定向 SSRF 防护** — 恢复 KS3 客户端的安全重定向策略，重定向目标继续经过 SSRF 检查，并避免把请求签名带到跨主机目标。
- **API Key 操作审计** — 知识库活动记录保存并展示发起操作的 API Key 名称，同时不把异步任务重新授权为该 Key。

### 已知限制

- **数据库驱动范围** — 运行时的 `DB_DRIVER` 当前只接入 PostgreSQL 和 SQLite；仓库中的 `migrations/mysql/` 仅作未接入的参考脚本，不能据此声称已支持 MySQL。
