# 专利工作台

本文面向使用专利检索、写作指导的工作区成员，以及负责开关、模型和数据清理的管理员。专利工作台采用对话形式，复用 HybRAG 的知识库、联网搜索、附件和引用能力。管理员启用后，成员从左侧“专利工作台”进入。

## 当前状态与前提

| 项目 | 状态与边界 |
| --- | --- |

| 本地检索 | 已实现；读取成员有权访问的知识库和会话附件，不复制专利资料库 |
| 在线检索 | 已实现；用户手动开启联网后复用现有网页搜索；覆盖范围取决于搜索服务，不代表完整专利数据库 |
| 写作指导 | 已实现；提供提纲、补充问题、修改建议及缺漏和一致性检查 |
| 默认研究范围 | 已实现；以中国专利为主，可按用户要求指定其他国家或地区 |

使用前需配置可用的对话模型；使用知识库检索还需按现有智能体规则配置重排模型（给候选资料重新排序的模型）。需要在线资料时，管理员先在网络搜索设置中配置并验证搜索服务。

模型可调用不等于能完成专利任务。本地 `qwen3.5:2b` 在本次样例中出现章节误标、自拟参数和工具调用异常；应使用本文复测过的模型配置，或先以同一材料验收替代模型。远程模型会接收提交的资料，使用未公开技术材料前应确认服务授权和数据使用边界。

## 使用方式

1. Admin（工作区管理员）或 Owner 在“设置 → 发布集成 → 专利工作台”启用功能。
2. 从左侧进入“专利工作台”，默认打开 `/platform/patent/search`。
3. 选择知识库、文件或上传临时附件，描述技术问题，或提供申请人、公开号等条件。首页提供常用问题入口。
4. 默认仅查本地资料。需要公开网页来源时，在输入栏手动开启联网搜索；页面会同步显示检索范围。
5. 查看回答中的检索条件、文献来源、相关性和证据范围。展开引用核对原始资料；只有摘要时，不能把分析当作全文或权利要求比对。
6. 进入 `/platform/patent/writing`，提供技术材料、交底书、权利要求或说明书，选择提纲、缺漏、表达或一致性检查。

历史详情地址分别为 `/platform/patent/search/chat/:chatid` 和 `/platform/patent/writing/chat/:chatid`。侧栏仅显示当前子功能的会话，支持重命名、置顶、单条和批量删除；窄屏默认折叠侧栏，仍可切换子功能及展开历史。

检索与写作指导使用 `builtin-patent-search`、`builtin-patent-writing` 作为默认 Agent（负责对话任务的智能体），也可按现有输入栏选择其他智能体。专利专属流程由对应内置智能体的提示词引导；改选其他智能体后，其回答遵循所选智能体配置。

## 检索与指导原理

### 专利检索

智能体根据任务选择现有知识库检索、文档阅读、附件阅读和网页搜索工具。本地查询仍受工作区、用户及资料授权约束；联网只有在智能体配置与本轮开关均允许时才可使用。

已实现：专利检索和写作会话仅使用本轮明确选择的知识库、文件、标签，以及当前会话的附件和正文。没有选择知识库时，不继承智能体的全库范围，也不会因推荐问题的来源自动扩大范围；需要检索整个知识库时，应明确选中该知识库。选择单个文件时，工具范围与提供给模型的近期文件目录均限制在该文件，不展示同库其他案例的文件信息。

单文件或标签范围还会移除知识库整体描述和画像（自动生成的库级内容概述），避免目录已收窄但整库概述仍带入其他案例的事实。显式选中整个知识库时保留这些信息。

兼容性：目录过滤在通用智能体构造处执行，也适用于普通和法务会话的单文件或标签选择；不扩大工具权限，不改变显式整库选择。专利会话的空选择限制则按会话归属单独执行。

提示词要求将用户技术材料与已公开文献区分，输出检索条件、相关文献、来源、证据范围和技术相关性。公开号、申请人、日期和分类号只填写来源实际提供的字段；申请日、公开日和优先权日分别标注。相同公开号在回答中合并并保留各来源，不推测同族关系。

上述字段提取和回答内去重由模型完成，尚无独立的专利结构化索引或确定性同族归并算法。网页搜索失败、服务未配置或结果为空时，应说明实际限制，保留已有本地证据；不能据此认定相关专利不存在。联网关闭时，不应声称完成了在线检索。

提示词要求字段组和技术判断附带本轮原文引用，正文长度限制不能替代引用要求。分块序号不得当作 PDF 页码，读取结果仍有下一偏移量时不得声称通读全文；需要完整核对时继续分页。引用生成和事实归纳仍依赖模型，不是新增的确定性校验器；需要打开引用核对对应片段，而不能只数引用个数。

### 写作指导

智能体先读取用户材料，检查技术问题、已有方案、关键特征、实施方式、参数及效果证据。权利要求检查覆盖术语、引用关系和说明书支撑；说明书检查覆盖技术细节、权利要求与附图的一致性。

输出以“原文位置 / 具体问题 / 修改建议 / 需补充事实”为主。可以提供提纲和局部措辞示例；不自动扩写整套申请文件。缺少材料时列出最少需要补充的内容，不编造实施例、实验数据或引文。

已修正首轮实测中的全库回退问题。两个内置专利智能体默认 `retrieve_kb_only_when_mentioned=true`、`memory_enabled=false`；服务端还按会话归属强制限制本轮检索范围。因此，即使已有工作区保存的智能体仍配置全库检索，专利会话也不能把空选择解释为全库。普通和法务会话保持原有范围解析规则，显式选中的资料继续接受原有授权校验。

写作提示词优先识别本轮任务：正文检查直接对照用户编号和原句，附件检查使用实际文件名、章节与完整附件阅读路径。重点检查数值、单位、时间间隔、指标、部件术语、效果证据和权利要求引用关系；缺少事实时只列待补项，不用自拟示例数值代替。无材料时先询问最少必要材料，不把公开专利当成用户自己的方案。

范围解析依据为 `internal/application/service/session_qa_helpers.go`，文件目录过滤见 `internal/application/service/agent_service.go`。修正前的失败记录保留在本文“开发环境真实写作实测”，不能当作当前版本的合格示例。

默认智能体的输出属于检索和写作辅助，不保证授权，不直接认定侵权，也不凭候选清单给出确定的新颖性或创造性结论。实际表现仍需结合原文和真实案例核验。

实现依据：`config/builtin_agents.yaml`、`config/prompt_templates/agent_system_prompt.yaml`；通用检索能力见[知识库说明](../../website-docs/03-features/02-knowledge-base.md)、[网络搜索说明](../../website-docs/03-features/11-web-search.md)。

## 会话、配置与数据边界

检索会话归属为 `workspace_mode=patent_search`，写作指导为 `workspace_mode=patent_writing`。服务端在专用创建接口固定归属，普通会话创建接口不能创建专利会话，更新元数据不能改变归属；创建会话分支时继承原归属。

会话列表按归属在分页和计数之前过滤。两个子功能与普通对话、法务助手互不混入历史；误入其他详情路由时，页面根据服务端归属跳转。历史会话继续采用现有用户与工作区访问限制。

两个子功能分别保存智能体、模型、知识库、文件、标签、外部工具、技能及联网选择。浏览器中的专利输入配置按用户、工作区和子功能保存；刷新、切换子功能和离开工作台时恢复对应配置。历史会话仍从 `last_request_state` 恢复上次发送时的输入状态。

专利会话禁用跨会话长期记忆的读取与写入，但保留当前会话消息和附件用于续问，避免把别的案例作为本案事实。此约束在异步任务上下文中同样生效，不受已有智能体的记忆开关覆盖。已经生成的错误回答不会被自动改写；修正前混入其他案例的会话建议另开新会话复测。

历史会话的模型优先于浏览器旧的最近选择和异步加载的智能体默认值。首次发送跳转后的输入栏保留发送时的模型，即使尚无最近选择缓存也不回退。用户主动切换模型仍会覆盖当前选择；调整智能体默认模型不会追溯修改历史会话或用户明确保存的模型选择。

关闭工作台会隐藏入口，并阻止专利会话后续的消息、问答、附件和产物访问；列表、统计、历史内容搜索及产物库隐藏相关记录。关闭不会撤销已经返回的内容，也不承诺中断关闭前已经开始执行的请求。重新开启后可以继续访问未删除数据。配置读取失败时，前端隐藏专利入口，管理员可在设置页重试。

Owner 在设置页确认清理后，删除两个子功能的会话、消息、建议、会话历史索引、临时附件和会话资源。共享知识库、其他工作台数据以及仍被其他对象引用的文件保留。附件和文件清理失败会返回错误，保留会话及必要的重试信息；清理不是跨数据库与对象存储的原子事务，失败前已成功清理的内容不会恢复。

清理仅处理开始时捕获的专利会话范围，包含此前已删除的会话，执行期间新建的会话留待下次清理。临时附件定时清理失败时保留记录并结束本批，等待后续重试，避免循环扫描同一批失败记录。

已实现：删除专利会话记录及其消息前，先停止该会话的后台任务（可在回答结束后继续运行的工作），再清理任务活动和通知。任务停止失败时保留会话记录，返回错误并重新允许该会话提交任务，便于重试；已停止的任务不会恢复。此门禁不回滚外层清理流程此前已删除的附件或文件。

实现依据：`internal/application/service/patent_workspace.go`、`internal/application/service/session.go`、`frontend/src/utils/workspaceMode.ts`。

## 部署与接口

部署目录 `.env` 可设置：

```dotenv
ICTREK_PATENT_WORKSPACE_DEFAULT_ENABLED=false
```

未设置或值无效时默认关闭。数据库尚未保存专利工作台配置时使用该默认值，设置页保存的开关优先；修改环境变量后重启后端才生效。VOS 打包的 Compose（容器部署配置）已传入该变量。

PostgreSQL 迁移为 `000156_patent_workspace_config`，SQLite 迁移为 `000061_patent_workspace_config`，为 `tenants` 新增可空的 `patent_workspace_config`。已有工作区不回填开启状态；空值遵循部署默认。会话继续复用已有 `workspace_mode` 列。

以下路径均以 `/api/v1` 为前缀。

| 方法 | 路径 | 权限与行为 |
| --- | --- | --- |
| `GET` | `/tenants/kv/patent-workspace-config` | Viewer（可使用工作区的成员）及以上，返回 `{ "enabled": false }` 配置 |
| `PUT` | `/tenants/kv/patent-workspace-config` | Admin 及以上，接收 `{ "enabled": true\|false }`；关闭不删除数据 |
| `POST` | `/patent-search/sessions` | Viewer 及以上，创建固定归属的检索会话 |
| `POST` | `/patent-writing/sessions` | Viewer 及以上，创建固定归属的写作指导会话 |
| `GET` | `/sessions?workspace_mode=patent_search` | 复用现有会话授权，支持 `platform`、`legal_assistant`、`patent_search`、`patent_writing`；非法值返回 `400` |
| `DELETE` | `/patent-workspace-data` | 仅 Owner；关闭工作台后仍可显式清理 |

创建接口和工作台清理接口沿用法律工作台的网页登录入口；消息读取和流式回答复用现有会话接口。专利功能关闭后的会话访问返回 `403`，跨用户或跨工作区请求沿用现有未找到或拒绝策略。
